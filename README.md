# A股分析终端

本地 Web 版股票分析软件：全量/增量数据更新、自选池、手动/自动选股、插件化交易策略、回测报告与 Excel 导出。

技术栈：Python 3.10+ / FastAPI / SQLite / pandas + React / TypeScript / Vite / ECharts。
数据源：东方财富行情接口（优先），腾讯财经接口（自动降级备用），或从本机 QMT 导出的日线文件**本地导入**；日线 K 线为**后复权**口径。

## 启动 / 停止

```bash
# 1. 后端依赖
pip install -r backend/requirements.txt

# 2. 前端（已构建过可跳过；改动源码后重新执行）
cd frontend && npm install && npm run build && cd ..

# 3. 启动（或直接双击 start.bat）
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8610
```

浏览器打开 http://127.0.0.1:8610

停止服务：双击 stop.bat（按端口 8610 结束服务进程及其子进程）。

建库最快路径：在 QMT 里导出后复权日线，再到「数据中心 → 本地导入 QMT 行情数据」执行全量导入（约十几分钟，含成交额），详见下方「本地导入 QMT 行情数据」。

## 六大功能

| 模块 | 页面 | 说明 |
|---|---|---|
| 基础数据 | 数据中心 | 「本地导入 QMT 行情数据」读取本机 QMT 导出的日线文件，分钟级建库且含成交额（推荐）；「全量更新」在线下载全部 A 股上市以来日线 + 基本面 + 12 期财报（耗时数小时，可后台挂机）；「增量更新 / 增量导入」补齐到最新交易日（新股票需先跑全量） |
| 股票自选池 | 股票自选池 | 默认 3 个池，可增删改名；池内股票可增删；点击股票进入个股详情页（K线/指标/财务） |
| 手动选股 | 手动选股 | 基本面（行业/市值/PE/PB/成交额/换手率/ROE/增速…）与技术面（MACD金叉、布林突破、多头排列、放量…）条件自由组合，须同时满足；结果支持单选/多选/全选加入自选池 |
| 自动选股 | 自动选股 | 5 个条件框，权重之和必须为 100；框内条件按满足比例计分，加权总分排序取前 100 |
| 交易策略 | 交易策略 | 内置 MACD+MA、双均线、海龟交易法、布林突破、KDJ 五个插件策略；插件放在 `backend/app/strategies/`，新增文件即自动发现；可勾选启用项 |
| 回测 | 回测 | 股票代码 + 时间范围（默认10年）+ 资金（默认100万）+ 手续费（默认0.0003）+ 已启用策略下拉；生成个股K线（标注买卖点）、大盘指数、行业指数三条曲线，汇总耗时/笔数/扣费盈亏/大盘与行业涨跌，交易明细可导出 Excel |

## 数据说明

- K线为后复权价格：历史K线不会因除权除息重算、长分红股早年也不会出现负价，适合指标计算与回测。
- 行业分类与行业K线来自所选数据源的行业板块；本地行业指数由板块成分股日线等权合成。
- 样本演示数据（13 只知名股票）可由 `python backend/scripts/seed_sample.py` 重建；正式使用请在「数据中心」执行全量更新。
- 全量更新可续传：已持有深度历史的股票只走一次窗口补齐，任务中断或个别股票失败后重跑不会重复下载。
- 数据源限速：腾讯行情接口每请求最多返回 640 根K线，请求过快会被其 WAF 拒绝（HTTP 501）。全量更新按全局最小间隔串行放行，并在被拒时指数退避（60s 起、最长 900s）。可用环境变量 `STOCKCN_HTTP_INTERVAL` 调整间隔秒数（默认 1.0，实测该间隔可整夜跑完不退避；调到 0.4 以下会被封 IP，例如 `set STOCKCN_HTTP_INTERVAL=0.8` 后再运行 start.bat）。
- 基本面快照的 市净率 / 换手率 / 成交额 三项来自腾讯板块成分股接口（它的字段名是 `pn` / `hsl` / `turnover`，成交额单位为万元），是当天收盘口径；「增量更新」会刷新这三项。
- 财报的 加权ROE（`fin_report.roe_weighted`）来自东财 `RPT_LICO_FN_CPD` 的 `WEIGHTAVG_ROE` 字段（半年报/年报为报告期累计值，不是年化）。
- 本地 QMT 导出的日线只提供 amount，日线里的换手率（`kline_daily.turnover`）由「流通市值 ÷ 现价」反推的流通股本估算，历史期内股本变动会带来偏差；选股用的换手率取上面快照口径的收盘值。
  「成交额(亿) / 换手率(%)」已挂进选股字段目录（结果表也有这两列）。
- 在线源与 QMT 的后复权基准不同，**同一只股票的历史日线不能混用两种来源**（`data_status.kline_source` 记录当前归属）：
  日线库为 QMT 导入时，「增量更新」只刷新股票列表/财报/指数并跳过K线补齐，日线请用「增量导入」；
  「全量更新」则被拒绝（避免把在线源的后复权价混入），确需切回在线源要先清空 `kline_daily`。
  非 QMT 库点「增量导入」同样会被拒绝，先做一次「全量导入」统一口径即可。

### 本地导入 QMT 行情数据

1. 在 QMT（迅投/券商端）里「导出数据 → 日线」，复权方式**必须选「后复权」**，并且**必须在收盘后导**（15:00 之后，建议晚间）：
   盘中导出的最后一根是不完整的日内快照（价格与量额都偏低），而「增量导入」只追加更晚的日期、不会回头修正它，只能重新「全量导入」才能纠正。
   按市场分别导出，得到
   `<导出目录>/SH|SZ|BJ/price_600000.txt`（或 `.csv`），表头为
   `timetag,open,high,low,close,volumn,amount`（`volumn` 是 QMT 的拼写，成交量单位为手）。
2. 打开「数据中心 → 本地导入 QMT 行情数据」，填目录路径（如 `E:\Project\QMT数据`），点「检查目录」：
   会报告导出文件数、匹配到的股票数、缺文件的代码、导出数据的截止日期，并在抽检发现末根收盘价与最新快照价一致时提示疑似不复权。
3. 首次或换口径时点「全量导入」（先写 `kline_stage` 暂存表，再一次性换名替换 `kline_daily`，中断不损坏已有数据；
   实测 4603 只 / 1595 万行约十几分钟）；日常点「增量导入」，只追加各股票最后交易日之后的行情。
4. 防误操作：导入前必跑一遍上面的检查，以下三种情况后端直接拒绝，除非勾选「强制导入」——
   抽检判定疑似不复权；匹配到的股票不足 `stocks` 列表的 80%（多半是路径选错或 QMT 导出没跑完）；
   全量导入时导出的截止日期早于本地库（会把历史倒退回旧数据）。增量导入只在日线库来源为 QMT 时允许。
5. 全量/增量导入后会把每只股票最后一根K线的 amount、换手率回填到基本面快照（只填空值，不覆盖在线数据）。
6. QMT 只供日线。股票列表/新股、基本面快照、财报、指数与行业板块仍只由在线任务维护：
   在 QMT 库上点「增量更新」即可，它会自动跳过K线补齐、只刷新这四类数据。新股要先出现在「增量更新」的股票列表里，
   它的 QMT 文件才会被「增量导入」匹配到；「全量更新」在 QMT 库上会被拒绝（见上一节）。

## 目录结构

```
backend/app/            FastAPI 应用
  datasource/           eastmoney.py / tencent.py / qmt.py(QMT 导出文件解析) / updater.py(全量+增量+本地导入任务)
  indicators.py         MA/MACD/BOLL/RSI/KDJ 指标库
  screening.py          手动/自动选股引擎（结果缓存5分钟）
  strategies/           策略插件目录（base.py 定义插件接口, builtin.py 内置策略）
  backtest.py           回测引擎 + Excel 导出
frontend/               React+Vite 源码；dist/ 构建产物由后端直接托管
data/                   SQLite 数据库（首次运行自动创建）
.tools/node             便携版 Node（仅用于构建前端，可删除）
```
